🎯 테이블 역할 및 비즈니스 목적
스마트폰/태블릿 등 모바일 현장 단말기의 로컬 작동 환경 및 중앙 ERP/MES 서버와의 데이터 동기화를 위한 REST API 엔드포인트 URL, 기본 다국어 설정, 최종 데이터 동기화 일시를 보관하는 핵심 설정 마스터 테이블입니다.
  • 오프라인 현장 단말기에서 중앙 서버(MES/ERP)와 통신하기 위한 Base URL 및 마스터별 개별 API(api1~api9) URI 로드
  • 마스터 데이터(사용자, 설비, 점검계획, 기준코드)의 최종 동기화 일시(sync_date_*)를 기록하여 증분 동기화(Delta Sync) 기준점으로 활용
  • 단말기 앱 기본 언어(ko/en/es) 및 점검결과 자동 백그라운드 전송 여부(auto_send_yn) 플래그 제어

🎯 테이블 역할 및 비즈니스 목적
통신이 두절된 음영지역(지하 피트, 변전실, 방폭구역 등)에서도 현장 점검자가 단말기에 정상 로그인하여 설비 점검 작업을 수행할 수 있도록 지원하는 오프라인 로컬 인증 및 권한 계정 테이블입니다.
  • 온라인 로그인 성공 시 사용자 계정 정보를 로컬 SQLite에 캐싱하여 이후 네트워크 단절 시에도 오프라인 로그인 허용
  • 사번(mob_user_id)과 암호화된 비밀번호(SHA-256 해시)를 로컬 대조하여 점검원 신원 확인
  • 사용자가 소속된 공정(uplo_proc_gbn: 01 상공정 / 02 하공정) 및 담당 역할(roles_json)을 기반으로 화면 기능 및 접근 제어
